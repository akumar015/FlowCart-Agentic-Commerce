The E-Commerce Paradox

The "Transactional Divide" in Modern Commerce

Status Quo: The Fragmented Funnel

AI acts as the sales representative, but is strictly locked out from being the cashier.

✕

Ejected at Cart: The instant the customer agrees to purchase, the chat stops and redirects to forms.

✕

Multi-Step Friction: Selecting addresses, entering card numbers, and waiting for SMS OTPs causes severe drop-offs.

✕

The Trust Deficit: Unrestricted LLMs hallucinate or miscalculate totals—platforms can't risk prompt-injection chargebacks.

FlowCart: True Agentic Commerce

In-app conversational checkout governed by deterministic, tamper-proof guardrails.

✔

Zero-Redirect In-App Flow: Spec comparison, real-time cart mutations, and checkout completion stay in chat.

✔

Pre-Authorized Mandates: Zero-click autonomous auto-debit via UPI Autopay for everyday purchases under ₹4,000.

✔

Deterministic Safety Gate: A hardcoded state machine node verifies spending limits and category whitelists before payment.

Financial Decision Engine

3-Tier Financial Guardrail Routing

PATH A (Priority 1)

Mandate Auto-Debit

Zero-Click Autonomous Settlement

Trigger: Active Mandate + Cart ≤ Mandate Cap (₹4,000) + Whitelisted Category.

Action: Razorpay recurring order debited server-side via stored token.

✔ Order confirmed in chat with zero redirects!

Sub-3 Second Execution
PATH B (Priority 2)

Payment Link Fallback

Step-Up Manual Verification

Trigger: Cart exceeds mandate cap OR contains non-whitelisted items (e.g. ₹70k iPhone).

Action: Generates secure hosted Razorpay link (valid 24h).

✔ SMS & email dispatched; webhook confirms order.

HMAC-SHA256 Settlement
PATH C (Priority 3)

Hard Rejection

Zero-Movement Block

Trigger: Cart grand total > User's per-tx credit limit.

Action: Gate programmatically halts checkout intent.

✔ Zero external API calls; violation logged to audit trail.

Zero Unauthorized Charges
